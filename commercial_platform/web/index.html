Realistic Local Model Weight Protection Limitations (Section 5 Engineering Disclosure)

Because local desktop inference executes on the customer's CPU and RAM, no software vendor can make locally stored model weights mathematically impossible to extract against a physical hardware owner with kernel or debugger (`ptrace`/`gdb`) privileges. Instead of making false DRM claims, NexoraAI V14.2 implements layered commercial controls: (1) Authenticated Single-Use Download Tokens with 15-minute expiry, (2) Device-Bound Activation Leases verified via public digests, (3) Contractual EULA Anti-Redistribution Enforcement, and (4) the API Edition for deployments where model weights must remain exclusively on vendor-controlled servers.

1. Offline Activation Public-Digest Protocol

The desktop client never embeds `NEXORA_LICENSE_PRIVATE_KEY`. Upon activation, the server issues a signed lease containing `server_signature_prefix` and `public_verifier_digest = SHA256(PUBLIC_SALT || license_id || edition || device_fingerprint || expires_at || sig_prefix)`. If a user edits `edition_code` or copies the lease to another machine (`device_fingerprint`), the digest check fails immediately.
